# PC・スマートフォン閲覧操作の点検
ページ送りをプレビュー下部に集約。前後・先頭末尾・番号直接入力・範囲スライダー・左右スワイプ（全体フィットでスクロール不要なときのみ）。和書等を想定してスワイプ方向を変更可能。拡大中はページ送りとパンを区別する。PCのキーボード操作はプレビューにフォーカスした場合のみ有効。複数ファイルは前後ボタン・下段一覧から切替、現在ページと倍率をセッション内のみ保持、個別に閉じられる。
画面いっぱい表示は閉じるボタン・Escape、背後をinert、フォーカス復帰。タップ領域44px以上を目標。モバイルは下部ページ操作を優先し、横向きの全画面でもプレビュー領域を確保する。
試験: Chromiumデスクトップ/狭幅とPlaywright WebKitのiPhone相当・Firefox。実機iOSのネイティブファイル選択、ピンチ、アドレスバー伸縮、VoiceOver、Android Chrome、Windows高DPIは別途確認する。合成ファイルによる試験は実業務ファイルの性能・再現性を保証しない。

ページ番号は送信時にのみ移動（入力中やフォーカス移動で失われない）。EPS表示方式もファイルごとに保持。単ページの場合はページ操作部を非表示。モバイル横向きの全画面も検査する。

連続閲覧: TIFF/JTDの通常倍率で再訪したページを最大3件・合計16MiBのLRUで保持し、ファイル切替時に解放。先読みは行わない。CIの初回Chromiumインストール時に無関係なMicrosoft apt配布元が403を返したため、Reader CIの一時環境のみ当該ソースを無効化。
